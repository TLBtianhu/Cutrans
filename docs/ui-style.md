# Cutrans 界面配色与材质

2026-11-06：依据用户提供的两张图标参考确定的方向。参考的是深靛蓝、冰蓝与紫色的关系，以及轻微反光的金属质感。图标中的大面积高光和发光不等比例移入工作界面；参考图片不作为本项目资产复制。

## 色彩真源

`uikit/palette.zig` 是纯数据模块。ImGui 与 NanoUI 分别适配它，不让 NanoUI 依赖 ImGui。界面共用相同语义颜色，布局与绘制仍归各自实现。

| 用途 | 色值 | 使用范围 |
| --- | --- | --- |
| 工作底色 | `#0D1024` | 大面积背景、编辑工作区 |
| 面板 | `#171D39` | 卡片、侧栏、检查器 |
| 面板反光 / 下缘 | `#232D4E` / `#141A32` | 低对比静态渐变 |
| 悬停 / 选择 | `#26315A` / `#2A365E` | 密集列表、导航与控件反馈 |
| 主文字 | `#E7ECFF` | 正文、名称、操作标签 |
| 次级文字 | `#A3AFCC` | 说明与元数据 |
| 冰蓝 | `#A4BCFF` | 主操作、选中项、焦点 |
| 淡紫 | `#A392F8` | 品牌与局部材质过渡 |
| 暖金 | `#F3C889` | 少量品牌点缀、拖放目标 |
| 错误 / 成功 | `#F18C9F` / `#8BC9B5` | 配合明确文字表达状态 |

亮色按钮使用深色前景 `#10152C`。颜色不能替代归属徽标、状态文字或焦点边框；预览内容保持原始颜色，不套界面色调滤镜。

## 材质层次

- 光源统一来自左上：上缘一像素冷色反光，下面保留低对比暗部。
- 反光固定、克制，不随指针移动，不引入闲置动画或闪烁。
- 品牌区域可以从冰蓝倾向过渡到紫色；文档工作区保持更均匀的深底。
- 面板使用轻微渐变、细边与短阴影，不用大面积玻璃模糊遮挡内容。
- 列表项与密集参数区平涂；依靠选择底色和焦点边区分状态，不给每行做发光金属效果。
- 圆角为控件 5、面板 8 个逻辑像素，间距与现有 4 像素基栅格一致。

ImGui 的渐变画笔只用于卡片与主要控件。NanoUI 使用代码生成的两张 16×64 BGRA 静态色片，进入已有图片图集并随面板缩放，不按帧上传背景、不读取外部图片。两种实现都不改变素材预览与媒体渲染路径。

## 交互与文字

日常界面说“资源库”“完整预览”“从原文件重新载入”“独立副本”。Catalog、Station、ABI、授权句柄与宿主路径等信息留给诊断接口。具有实际创作意义的 `.cut` 声明与节点表达保留。

暗色是本阶段落实的默认视觉，不增加尚无完整合同的主题切换功能。所有输入框、菜单、编辑器、任务栏均使用同一暗色语义，避免只改首页留下浅色输入框。

## 验收边界

构建、状态测试与离屏 D3D/CPU 对照由项目标准验证执行。它们验证功能、非空绘制与后端一致性；真实窗口的观感、不同 DPI、IME、焦点与长时间使用舒适度仍需要用户体验反馈，不用截图或真实键鼠自动化替代。
