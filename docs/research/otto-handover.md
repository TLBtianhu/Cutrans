## 五、明确的产品决定（不要翻案）

- **库格式只支持 v2**：旧版本库报 `UnknownVersion`，但**应用仍能开**（空库 + 提示），**不再保留迁移分支**。
- **浏览模式只读**：不写源目录、不写库、不写设置（有逐字节证据）。
- **便携版不自动更新**；安装版覆盖升级时数据逐字节保留。
- **默认构建目标 x86_64_v2**（SSE4.2），开发机需要更高优化用显式 `-Dcpu`。
- **预览不是宿主启动**：预览、Shell 打开方式、拖出移交是三件事，不共用动词。

## 六、正在精化但**未定稿**的部分（别照搬）

- **文字清晰度**：D3D 灰度已修（0.56），小字号定位已修（0.57），但用户仍觉得不够清。**剩下的是 gamma/字族/hinting 的调校**，在与原生 ClearType 对照中。
- **响应式布局**：已改为连续分配，但"是否顺手"还在打磨；**不整套提给上游**（上游已有 flexbox），只把通用的小修复单独提（如 #72）。

## 七、工程纪律（最近踩出来的，供参考）

1. **默认 target 必须钉基线**，不能 native（否则老 CPU 直接非法指令、静默退出）。
2. **判断渲染质量用真实窗口 readback**，`--nanoui-snapshot` 固定走 CPU，不能判 D3D。
3. **任何优化都要能反向失败**（关掉开关必须变差），否则分不清优化和机器安静。
4. **测性能前确认是 release**（debug 会差一个数量级）。
5. **删除类操作先列完整路径清单确认**，只按 `.lnk` 真实目标判定，**绝不按文件名子串通配**。
6. PowerShell 写 JSON **不要带 BOM**；PowerShell 函数名不要撞别名。

## 八、给 Cutrans 的接入建议（简版）

- 用 **vendored 固定版本** nanoui，默认 target 钉 `x86_64_v2`，不用 WebView2 就 `.webview2 = "none"`。
- 缩略图/图集/PCM 都设**硬预算并按峰值**。
- 预览统一带**覆盖范围**（前缀/分页/是否完整），不把部分内容冒充完整对象。
- 详细版见 `docs/research/nanoui-usage-guide.md`；边界模型见 `docs/research/otto-source-station.md` 与 `docs/research/otto-source-station-reply.md`。
