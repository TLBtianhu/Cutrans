# 2026-11-10 NanoUI 同步到官方 v0.14

本片把 vendored NanoUI 从 fork `00e5813`（0.12.0）切到官方 `7b32272`（v0.14.0），并采用官方 `src/windows/chrome.zig` 的自绘标题栏方案。旧的 borderless `WS_POPUP` + `WM_NCHITTEST` 实验被移除。

## 基线

- 官方仓库：`https://github.com/justrach/nanoui`
- 基线：`v0.14.0` / `7b3227295d37982306eee7b87b3e1fbbb76b3970`
- 归档 SHA-256：`8b8a2abba224dfda294e0c3b91144866137e48ecf60b5f11a5815cd0091c4765`
- vendor 只保留官方源码包路径（`src/`、`tools/`、`third_party/licenses`、构建文件和 provenance），不包含 `apps/`、`examples/`、`lean-proofs/` 等应用/证明目录。
- `dependencies.lock.json` 的有效树：455 files / `d946cb8d3982b8057c80c49cb0e69bf88f939e162386b0a071bb6bc61ca5d1f9`。

## 本地补丁（6 个文件）

1. `src/ui/ui.zig`：Windows 导出 `ui.d3d11`，供 Cutrans offscreen D3D/CPU 对账。
2. `src/ui/widgets.zig`：`ButtonOptions.window_maximize`，让自绘最大化按钮得到 `HTMAXBUTTON`，保留 Windows 11 Snap flyout。
3. `src/window_types.zig` + `src/windows/window.zig` + `src/windows/surface_gpu.zig`：`Options.on_present`，只在 GPU swap-chain present 成功后回调；GDI 不触发。Cutrans 用它做 VM frame receipt。
4. `src/windows/app.zig`：`Options.kv`（默认 true），Cutrans 传 false，避免隐式读取其他 NanoUI app 的持久目录。

已退休的本地补丁：

- D3D11 per-frame texture upload：v0.14 已有 `ui.texture`/`d3d11_texture`。
- CPU stride parity：v0.14 的图像/纹理路径已处理最后一行。
- fork 的 `trace`/`frame_timing`/`fontindex_win`：当前源码引用和测试不再需要；未带入。
- `border_resize.zig`：由 `chrome.zig` 替代。

## Cutrans 应用侧

- 桌面窗口改回 `decorations=true` + `title_bar=.hidden`；`chrome.zig` 保留原生 resize、Snap、系统菜单、DWM 阴影/圆角。
- 自绘标题栏仍保留最小化/最大化/安全退出；最大化按钮设置 `window_maximize`，标题栏设置 `window_drag` 和 `c.title_bar_height = 38`。
- `Window.setFullScreen(true)` 仍默认最大化；F11 继续调用 `zoom()`。
- 资源库 offscreen 渲染改为设置 `renderer.textures = tester.ctx.textures.items`，再调用 v0.14 的 `draw(instances, size, scale, clear, target)`。
