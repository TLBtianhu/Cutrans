## 十、时机与消费(调度立法闭环)

- **双轨时机**:点播(拉取保底,接口自带行为,非插件)+预产(插件:批量拉取任务机,进度/取消/并行);两轨灌注同一批物化点,账本幂等(内容由声明唯一决定)永不冲突。**调度择时生,且择时本身是插件**(宿主只提供物化点,不提供立场)。
- **时机三轨+优先级**:前台点播(用户在等)>预判窗(seek 监听=意图信号翻译,移戳=预览意图)>闲时全量(备胎,逐帧产逐帧压 L2)。
- **播放轨=deadline 驱动**(33ms/帧):产速>播速=窗前进;产速<播速欠账三选(等/跳帧/降级低清档);**音频优先铁律**(爆音恶劣于丢帧万倍);自适应窗口(领先收缩,欠账扩大,上限=内存)。四轨灌注同一分层账本。
- **播放门禁律**:allowed(t)=has(t)——这帧没有就不允许播放;**播放头永不撒谎**;进度条=账本可视化(物化区间亮);等/跳/降级=门禁之上可选政策件,默认全无。先例:AE RAM 预览只播已渲区间。
- **欠账形态律**:帧化体系下欠账的合法形态只有"卡顿/停帧/停窗",禁止"变调/变形"。机理:微观时间(帧内频率)与宏观时间(帧序)解耦,欠账只伤宏观;卡顿=技术停顿(读作"加载中"),变调=内容身份被毁(反例:AE 慢渲染拿连续波形慢放=varispeed 人声变鬼)。视频侧天然免疫(离散图像无音高可移)。
- **消费物种分层**:机器界(流效果器链内递归)只走保底轨(点播现产/读账)——需求是算出来的不是猜的,零博弈;人类界(播放/预览)四轨政策。递归穿透两界(链式拉动每跳都是保底),策略只长在人界一侧。
- **帧状态机四态**:未产/在算/L2 有/L1 有(have[] 的胚胎长成)。
- **预览骨架:输出插件三件套(2026-10-10)**:Windows 的视频与音频 API 逻辑确实两套——**视频=呈现队列**(推帧进去,vsync 排期显示;显示器有"保持"性:上一帧会一直亮着),**音频=流式填充**(DAC 持续掏空缓冲,空=爆音;声卡无"保持"性)——物理差异真实存在,但统一到帧抽象后差异归参数不归架构:**输出插件只写三件套=①钟**(谁来敲:vsync/DAC 周期/定时器)**②填**(帧→API 调用,模态专属的唯一代码)**③欠账政策**(跳帧可忍/缓冲深度防爆音);共享骨架=时钟门禁引擎(睡到钟敲→has(t) 门禁→填→睡下一周期)。**AV 同步=帧号索引算术**(对齐采样率律的兑现:音 n=视 n=同一段 1/30 秒,零对齐逻辑);行业先例=GStreamer BaseSink/mpv 输出层。
- **平台口岸全景与最大兼容法(2026-10-10 调研,三官方源已核实)**:显示栈共同形态=**交换链+vsync 翻页+帧时序反馈**(Windows DXGI flip:共享后缓冲零拷贝+present statistics+glitch 跳帧恢复——欠账三选的行业实证;Wayland:frame callback+wp_presentation_feedback 精确呈现时间戳;macOS:Metal drawable+CADisplayLink;Android:SurfaceFlinger+Choreographer;Web:rAF);音频栈共同形态=**周期缓冲填充回调**(WASAPI:shared 模式系统混音+SRC/exclusive 直通;MMCSS 加权;CoreAudio 拉式回调;PipeWire 图;AAudio;WebAudio Worklet);设备失效=标准事件(WASAPI AUDCLNT_E_DEVICE_INVALIDATED)——口岸需重开政策(热插拔红标/自动切默认设备)。GPU=wgpu 一统(已 vendored,D3D12/Metal/Vulkan 归它)。CPU=Zig 目标特性+@Vector 绑期选核(注意 Apple Silicon 缓存行 128B、页 16KB)。**规范生成律**:硬件能力先行→厂商私 API(CUDA/ASIO/Metal)→联盟标准化(Khronos 收编 Mantle 成 Vulkan/W3C WebGPU/VESA/HDMI Forum)→平台所有者拍板——与我们的格式法同构(先验装机量决定合法性)。**我们的最大兼容=口岸法**:内部纯度不动(帧抽象/f32/2048 窗/帧率上限),平台后端=口岸插件(三件套:钟/填/欠账),初始化能力握手(刷新率/采样率/声道/色彩空间/像素格式),一切转换在口岸(重采样/像素格式/色彩空间);档位政策:L0 全保真/L1 主流(60fps sRGB 立体声 48k)/L2 低清档直通。
- **音频重灾区的四因与口岸对策(2026-10-10)**:音频比视频难适配的四因——①**硬实时**(欠账=爆音,物理刺耳;视频丢帧可忍:感知预期律);②**多钟域**(每个 DAC 自己的晶振,设备间漂移是常态;视频只有一个 vsync);③**监听延迟刚需**(乐手<10ms 往返才不影响演奏;视频 30ms 无所谓);④**驱动质量方差**(ASIO 生态/内核流/厂商私栈)。Logic 只在 Mac=苹果拥有(平台锁定)+CoreAudio 一条栈质量高(鸡生蛋蛋生鸡);Windows 音频四条路(WASAPI shared/exclusive/ASIO/厂商直驱)就是方差的证据。口岸对策:音频后端=口岸插件(缓冲周期协商/失效重开);**播放主钟=音频 DAC 的硬钟**(音频钟为锚,视频跟随——mpv 行业通例),漂移补偿归口岸。
- **设备扫描与握手时机法(2026-10-10)**:设备清单=**OS 设备树的物化视图**(真源在 OS,表可重建);**扫描=用时惰性**(设备枚举毫秒级廉价——不像插件扫描那么重,故不用 DAW 式落盘缓存,更不启动全扫);**握手=口岸插件实例化时**(能力查询+档位协商:刷新率/采样率/声道/缓冲/像素格式;**不预览=零握手,headless 编辑永不见设备**);**热插拔=事件驱动失效**(OS 设备变更通知→内存命令→作废视图→重扫重握手;活跃设备消失=失效转移政策:自动切默认设备,无设备=红标——编辑不依赖设备,红标只标预览/输出插件);GPU=wgpu requestAdapter 同法(惰性+偏好提示)。设备表词汇=查询/set/clear/merge;用户选的设备住配置(政策),视图住内存(机制)。
- **绑期与现场分家(2026-10-10)**:编译期定**语法**(ABI/指令集/系统调用形状/端序,Zig target+comptime 特化全包)——"怎么说话";运行期对**现场**——"世界长什么样,而且它随时变":①**探测**(CPU 特性 cpuid/getauxval、GPU 档位、设备清单、刷新率);②**协商**(格式档位握手);③**跟踪变化**(热插拔/设备失效/GPU TDR 重置、显示模式切换 HDR 开关、电源/热节流、P 核 E 核混合拓扑、NUMA);④**生存政策**(沙箱权限:macOS entitlement/Android 运行时权限要摄像头麦克风;glibc 符号版本地狱——新 glibc 编的二进制老系统跑不了;同 API 不同 OS 版本行为差)。**口岸插件=探测+协商+监听变化三件套,绑定的是政策不是常量。** **引擎只给机制,时机归软件(2026-10-10)**:引擎提供探测/协商/监听三件套的 API(纯函数/对象+变化订阅通道),何时调用全归软件(政策层)——机制与策略分家、机制与触发分离在口岸层的兑现;**引擎零隐藏动作**(不自动扫描、不自动重试、不偷偷预热),变化只经订阅通道上报,何时响应、重不重建归政策;例:预览插件实例化时握手是政策,启动时预握手热身也是政策,引擎都不管。**"没有"=物化状态命题,不是存在性命题**(2026-10-10 用户防误会):帧作为身份(流,t)由声明唯一确定(幂等律),**永远"存在"于声明层**;"没有"只指**字节层未物化**(未产/在算),可安全抽象为"无"——因为产帧确定且随时可重产/重解,"无"随时可变回"有",语义不丢。死状态 0×0=此抽象的 sentinel:返空帧不是"这帧内容是空的",是"未就绪"占位(合法帧必有画布尺寸 w>0,永不与真内容撞车);has(t) 问的=四态中的后两态(L2 有/L1 有)。
- **全量压缩态模型的合法性**:首开付全量、编辑后付受影响锥(哈希自动划范围),之后永远是播放器;复杂度守恒——把空间复杂度换成时间复杂度;压缩的真身不是省空间,是消管理;边产边看:have[]=进度条。
