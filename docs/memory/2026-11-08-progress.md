## 目标形态继续遵守的约束

- VM／Runtime持有文档、资源、授权和Job真源；Host承载生命周期和自主推进，Shell／App持有投影与本地交互。GUI、CLI与Agent的目标是共享同一业务语义，不能各自复制规则。
- 本地外部来源、云来源与VM托管内容分区；本机浏览、资源管理、桌面、CLI、类PS编辑器等按独立App组织。下载器继续是专门App。建议名“本机文件／资源库／云端文件”尚未定为正式名称。
- 其它消费App使用VM资源身份；外部直接拖入消费App也走“登记→交付”。默认只读引用；显式独立化保留ID和显示名，以状态标记区别，不强加“副本”后缀。登记成功与消费失败分别表达，交付重试不重复登记。
- 普通正文直接编辑限VM托管区；外部出境为显式复制，不借来源读取授权开放原件删除、移动或写回。资源库移除引用与删除外部原件是不同语义。可导航全盘不要求启动递归扫描或预先登记全部文件。
- 文档、工作正文、固定采用版本、Station与可重建缓存分别管理；自动同步只归可选插件。共享深靛蓝、冰蓝淡紫、少量暖金及克制金属高光；视觉迁移不改变VM业务权威。

以上是目标约束，其中尚未实现的App、通路和权限收口仍按下表处理，不能用目标定义代替当前代码。
