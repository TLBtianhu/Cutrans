## 六、素材与器具(源宪法)

- **素材无时间**:素材连协议格式都不算;时间诞生于启发器(器参含时长/速度/时间基)。素材层薄而稳:id+地址+来历,无 schema;新格式=新启发器插件,素材层零改动。**启发器=协议世界的入境口岸,导出器=出境口岸**(格式混沌集中口岸,协议内部严格=细腰)。
- **内生/外引**:外引(mp4/mid/png)=记路径;内生(像素画/音符序列/参数谱/遮罩)=工程文件是其硬盘本源,保存=打包 .cft。**协议无关者真源性更高**(同一音符序列任意采样率可用)。外引是分享工程的唯一断点→分享时收集打包。
- **器具=可执行素材**:同为"名↔路径↔指针"外源内容,都要从硬盘 carry 进内存;区别仅落地段(数据段/代码段)与消费方式(被读/被执行)。四表对称:素材{名↔路径,名↔指针}+器具{名↔路径,名↔指针}。
- **源宪法五词**:实例/源/地址/名字(住实例内部声明,≠文件名——文件名属于地址)/表(源内 名↔地址 的内存索引=扫描∘分析的缓存)。**四动词**:扫描 scan(源→地址集)/分析 analyze(地址→名字,peek 本体)/载入 carry(上级地址+下级地址→实际下级地址;下载/加载/上传皆是载入;载入永不发明地址只接收地址)/删除 remove(输入只有地址)。
- **表=可重建物化视图,不是事件流水账**:随便坏,随时重扫真源重建;用户数据(收藏/评分)与视图分离(rebuild 永远安全)。表词汇:查询/set/clear/merge。**机制与触发分离**:何时扫是策略(手动按钮/监听/定时),不是机制。
- **id/地址对偶**:引用走 id,解析走表;地址可变,谱不动。发号按作用域分级(文档级小号可读自包含+库级全局唯一),不按类型分级。
- **身份三层链与双态发号(2026-10-10,用户重构)**:三类实体统一身份链——素材=硬盘路径→内存共享 id(强指针)→name;效果器=硬盘路径→内存共享 id→name;合成=内存共享 id→name(**无硬盘路径**:合成不落盘,流是模拟的承诺机器,无硬盘真源,故少一张硬盘↔内存对应表);name 与 id=变量名与指针的关系(命名任何实例都有必要,多一张 log n 的表);**三个发号器全内存共享**(为将来内存空间中多 .cut 文件共享引用)。**双态发号**:.cut 文本态=文档级小号(自包含可读),装载期重映射到工作区级大号(链接器同构:局部符号→全局地址;跨文档引用需求的扳机兑现)。~~双态发号~~**发号器=共享 id 虚拟机(2026-10-10 用户修正,废双态)**:整个内存空间=三个共享发号器(素材/效果器/合成;一个全局计数器跨三类也合法,表由上下文分)——**id=地址,地址空间共享故 id 共享,共享号即完备,小号无必要**;.cut 文本带的号=出生时的号,装载进工作区撞号时重映射(链接器同构,一趟过);**发号器组件=id 虚拟机**(单调递增地址分配引擎,有独立制作价值——它就是这台 VM 的地址分配器)。
- **VM 引擎的代码区定制(2026-10-10)**:效果器住代码区(OS 装载器管,X 执行权限是 OS 的独门先验),素材/合成住堆;VM 引擎不复制执行权限,两形态:原生档=**利用** OS 装载器授予(平台法老法:平台性住 source/);wasm 档=**自己就是代码区**(wasm 运行时=我们自己的代码区管理器,沙箱即红标区)——OS 对称化愿景(远期取消 DLL 特权)的过渡形态。
- **多 cut 管理=浏览器多页面同构(2026-10-10,用户)**:文档=标签页(各自的树/各自的撤销史),工作区=浏览器进程(共享发号器/共享表/素材缓存),要硬隔离=多进程(标签页进程同构)。
- **id 虚拟机的便利清单(2026-10-10)**:id=虚拟地址,id↔地址表=我们的页表(OS 的 VA→PA 同构,两层虚拟化各管各命);单调发号=O(1) 分配(计数器即分配器,无空闲表无碎片无合并);**id 即下标**(id 从 1 稠密增发→表=平坦数组,查表=地址算术一条 load,哈希表全省);**无 ABA 永恒**(空窗墓碑,代际混淆结构上不可能——老引用指向死 id 永远可检出);整树复制=数组 memcpy;序列化免排序(id 序=数组序,diff 友好);**缺页同构=惰性物化**(表项不在场→现场物化——物化点律=demand paging);id 分片并行免费(worker k 吃 id≡k mod N)。代价诚实:空窗内存(墓碑 compact 归政策),id 膨胀(64 位无所谓),表 append-only(与日志哲学一致)。
- **帧的身份=坐标,不发号(2026-10-10)**:有内在坐标的实体(帧=(流,t))**坐标即身份**,不占发号器(顺序时间内在律:帧的身份=它在时间轴上的位置,生而自带);无内在坐标的(合成/素材/器)发号器铸 id;**原指针永不当身份**(指针可变,身份永存)。解析同构:L2 按 t 索引→当前物理指针,与 id→地址表同构(键从单 id 换成复合键(流,t));发号器只服务稀疏实体(树节点/素材/器),海量帧走坐标——id 空间不被帧淹没。
- **坐标抽象零引入(2026-10-10)**:坐标不是新层,是帧**自带的属性**(流协议本来就说 t,get(t) 是既有接口)——引入 id 才是加层,不引入=减层;坐标↔地址的表=L2 容器本身(**存储与寻址同一张表**,不新增维护);坐标单增且免费(流延长即坐标增发,零发号器);**坐标表=易失缓存**(帧可再生,条目随便死随便重建),id 表=持久登记(声明不可再生,必须长存)——活法不同。抽象到此闭环:坐标(帧)/id(合成素材器)/name(插件),三层身份三张表,表那头是地址,**没有第四层**;引入判据=实体缺内在坐标且需全局唯一时才铸 id。
- **id 虚拟机的开发期红利(2026-10-10)**:运行期=基质(引用/消息/缓存/引用纪律全靠它);**开发期=工具**——①可观测性(台账式调试:查表不抓指针,按 id 打点日志,命令日志回放 bug);②确定性(发号确定→测试可复现,冒烟断言按 id 写);③重构自由(实现搬家只改表,引用不动);④热重载(状态按 id 键存,代码换了状态还在);⑤AI 可读(按 id 审阅/diff/三方同构)。边界:身份实体才配 id(合成/素材/器/流),临时草稿区(scratch/工作缓冲)直接裸指针——不是所有东西都配 id,不配的就别配。**效果器的 name 二分**:OpDecl 签名(名字+版本+abi)管装载校验与依赖检查,表 name 管索引引用——签名变(版本升级)而表名不动,同路径替换文件表索引不受影响,**校验与引用解耦**(系列插件签名互相关联的联动更新游刃有余)。
- **插件单件制**:一 .cop 一 op 一名;真实身份=PE 内声明(name+version+abi),文件名≠身份;冲突的检测与解决同落在文件粒度。
- **工程文件消解为配置层级**:两层索引不套娃(顶层键=闭集先验,下层键=开放集;ELF 同构)。**后缀只是衣服,声明才是身份**。
- **自由加载/索引=现代化三方向的公共地基**(2026-10-09 重申):万物各自成件、可独立加载(素材/伪代码/器/表),尽情拆解随意摆放;没有"必须整体装载的工程"这个单位,只有按需装配的件。分表红利:空白工程=只加载预制器具表;只加载素材表=素材暂存管理器;表=可分发制品+最小版本钉住单位(lockfile)+热替换单位。对三方向的意义:开源化=任何件可单独分发/复用/钉版本;插件化=件与件无隐藏耦合,装配器随时重组;AI 化=agent 可按粒度取食(只读 .cut 不碰素材,只搬表不碰内容)。这正是"现代剪辑软件"区别于 AE 式整体工程的定义性特质。
