精确删除白名单只有上述两个绝对路径。执行前复核相关Zig／测试／Cutrans进程为0、两目标及父级没有联接或符号链接。逐对象核对文件身份和物理路径，持有祖先目录句柄防止重命名替换，按已核对句柄删除；目标内容变化、新出现对象或占用均停止并记录错误。没有调用旧卸载器，没有更改注册表、快捷方式、服务或其它产品配置。

源码、主`.git/`、工具链、依赖、全部`scratch/`证据、当前`zig-out/`产物、旧安装／会话数据及私有历史／旧Release备份保留。当前五组产物的文件哈希、已验收源码ZIP与私有历史bundle的SHA-256在删除前后相同。盘点遇到的11个验证联接均跳过，没有跟随删除。
