## 十三、内存哲学

- **栈管控制流**(调用帧、参数、帧外壳提货单、引用;预判领土,LIFO 先验换性能;ALGOL 为递归而生);**堆管数据**(像素缓冲、树节点、物化视图;自由领土,触发驱动);**静态区**(编译期定址,装载期映射,进程级);**资源段 .rsrc**(对外档案,不执行可读,OS 是读者;不想被 OS 第一眼看到的写静态区)。
- **小≠栈**:树是"相对流而言小"的堆上动态结构;大东西永远不走栈。
- **公开即长寿,长寿即缓存**:没有绝对的公开/私密,只有作用范围;函数内变量无神奇能力。
- **句柄=间接层凭证**(指针是其物理形态之一);Stream 句柄走值,本体走堆。
- **DLL 装载=全段映射+依赖解析+重定位+TLS+DllMain**;静态区每模块一份;**CRT 同族律**:载入方与被载方必须同运行时家族(C++ 实测:Debug .cop+Release 宿主=LoadLibrary err 126)——Zig 无 CRT 包袱,此律在 Zig 域退化为"ABI 同族律"。
- **内存地图**:堆=素材+合成流+参数流+树节点;代码段=器;栈=调用帧。素材池=进程级共享堆缓存(不是静态区);独立堆=所有权纪律非硬件墙,真墙用进程。
- **CPU 缓存层级与搬运经济学(2026-10-09)**:registers/L1/L2/L3=**硬件影子**(自动、不可寻址、以 64B 缓存行为单位,SRAM 在 CPU 芯片上);堆/栈/静态区=**软件分区**(全住 DRAM 地址空间)——两套分层是不同维度,栈快在"分配免费+行必热",不是"栈的内存更快"。**同一地址空间内没有"传输",只有读和写**:传帧=传壳(指针+尺寸,几十字节),零搬运;只有 CPU 真正触碰像素才产生搬运——**CPU 是过路站不是仓库**,33MB 帧以 64B 窗口流式过 CPU,从不"进 CPU"。虚拟内存=地址空间抽象不是地点,DRAM 才是地点;TLB/页表=翻译机;swap=OS 的落盘保底。传输只发生在两个内存域之间:网络、进程间、PCIe DMA 到显存。媒体编辑是带宽游戏:算(ALU,ns 级)与搬(总线,预算制)是两套资源,帧成本≈字节数/带宽;融合流式消费(解码直接喂下游不过 DRAM 整趟)是压缩红利的真身之一。我们的 L1/L2/L3=软件政策(帧粒度对象,住 DRAM),与 CPU 的 L123 **重名不同物**。**程序员对缓存的正确心智(2026-10-09)**:缓存对正确性 100% 透明(可永远当它不存在,程序不会因此错);对性能则不是"考虑它"而是"考虑自己的访问模式顺不顺它的物理"——顺序流(喂饱预取器)/行对齐(每行 64B 用满)/时间局部性(趁热消费,融合的真凭)/工作集<档容量/多核防假共享;仅有的"指令"(prefetch、non-temporal store)也只是提示不是命令。帆船律:不能指挥风,但能调帆。**正因为硅的政策是死的(LRU 族),我们才在软件层自建 L1/L2/L3 立法**——"重算成本×fan-in"只有软件懂;机制与政策分家的最深处:硅=机制带死政策,我们=机制+我们的政策。
- 拷贝 vs 引用:8 字节值语义免费,33MB 贵;值对外(帧按值,互不别名),引对内(账本纪律)。
