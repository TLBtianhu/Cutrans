## 三、树(声明层)

- **树 = comp 来历的完备/无损/无歧义声明**;每个 comp 各自一层谱(其它 comp 是不透明基石,id 引用),完整谱系=一层谱靠引用拼成的格。**comp** = 统一传输介质上的一个实例(视频域=像素流,音频域=PCM 流);树的作用对象只能是 comp。
- **一 comp 一生**,生只三种:**启发**(无中生有:素材解码/声明式渲染/纯器参生成,0 路同协议输入)/**变换**(1→1 过效果器)/**聚合**(N→1;语义被 层级/相对时间/相对位置/缩放/透明度 完全描述,**聚合器唯一,无帧聚合器**)。等价 SSA/三地址码:每个中间结果具名(comp id),可缓存、可推理、可多处引用。
- **Node = { birth, op, ins, params, in_params }**(C++ 形态):birth=生种类;op=器名(引用走名,解析走表);ins=主路同协议输入 comp id(0/1/N);params=器参;in_params=聚合参数(与 ins 平行,一路一套:x/y/opacity/t……缩放旋转后置)。**Zig 版红利:Birth=union(enum) 带载荷**(inspire/transform(in)/aggregate([]AggIn))——"变换零输入或双输入"在类型系统里写不出来;平行数组在 aggregate 载荷里融合成 AggIn{in, params}。
- **器参二分法**:信号参数(逐帧消费)= comp id 引用参数流节点;配置参数(枚举/模式/路径,定结构)= 字面值,产生前读一次。枚举动画走选择器效果器。判据=语义可钉死性(mix 无绝对定义→归内参)。参数槽两种构造必须显式(C++ 具名工厂 v()/r() 防 variant 静默转换;Zig union(enum) 天生免疫)。
- **树记 id 不记指针**(别把会死的针焊进不死的树);名字解析成指针是引擎层的事。树=内存态,.cut=硬盘态(+LLM 阅读态),同一物两态(parser 后置)。**两态分家精化(2026-10-10,用户)**:硬盘代码与内存代码是两回事——内存树=运行时真源,落盘=显式声明的保存动作;与前端的区别不在"文件与内存分离"(家家都有),在**内存态是声明还是涂鸦态**+**往返是否无损规范**(我们 emit∘parse 恒等;前端 DOM 序列化是事后诸葛,文件从 JS 跑起来那刻就死)。
- **组合=结构体(2026-10-10,用户自觉)**:Blender 场景分析——编辑视角渲染器与摄像机渲染器输入同两组实体(正方体/球),只差摄像机流;把共享实体集打包成**组合**(带 id 的声明包,非聚合器),渲染器只引组合 id+自己的摄像机流。**组合=结构体/类的剪辑形态**:参数/流/组合=数字/堆上数组/结构体(同一整块空间+不同先验布局);id=指针;数组=同型定长的特殊类(顺序先验);参数也可带 id(常量启发器产出的数配 id——`a=2` 就是启发);调用插件=引用 id≈函数指针调用(Zig 的 const 绑定函数指针同构)——剪辑与编程的鸿沟在此闭合。
- **.cut 变量创建律(2026-10-10)**:创建=具名绑定(`c1=gain(c0,…)`),**声明即初始化**——声明=完备来历,无"先声明后赋值"的半态;类型不显式标注——**类型=产方器的输出制式**,自动推导(绑死律);常量=`p1=const(0.8)`(常量启发器发 id);素材=素材表登记(mat id);**无 null 无未初始化态**:每个名字一写出就完备。
- **参数节点与视频节点同表同 id 空间**(comp id 万能)——模态平等。
- **树的自身形状与身份三域(2026-10-10)**:树=Comps(AutoHashMap(u64,Node))+发号器+入口约定(**无根**:渲染对选中的 comp 求值);边=节点内的 id 引用(Birth 载荷与 params 的 r);谱/素材分表。**单调发号白赚无环**:id 单调递增+引用只能指向已存在的较小 id⇒DAG 天然无环,拓扑序=id 序,零环检测代码。**身份三域,全局 id 引擎不需要**:文档级 id(合成,本地创生,发号器)/分发级 name(插件/模态包,唯一性归仓库单件制)/库级 id(素材,引用走 @id;名字=显示元数据非身份;跨工程=.cft 打包,导入时撞号取新号并改写引用——素材不靠名活着,撞名问题不存在)。
- **内联=效率+可读档,非完备性必需(2026-10-10,用户)**:理论上一切皆可引用(mp4 解码启发器的输入是素材名引用;常量启发器的输入也可以是 txt 文件名)——内联不在完备性里,它是**效率档**(零税)+**可读性档**(平凡值直读 `w:1920` 而不是为一个常量建流)。
- **.cut 语法↔树结构↔Zig 形态定案(2026-10-10)**:语法最小集=①具名绑定 `name=expr`(绑名即引用);②器调用三形:启发 `c0=testsrc({w:1920,…})`(0 路)/变换 `c1=gain(c0,{value:p1})`(首参=主流入)/聚合 `c3=over([{in:c1,x:0,opacity:1.0,t:0},{in:c2,…}])`(N 路,每路自带聚合参数);③器参表 `{k:v}`;④常量启发 `p1=const(0.8)`(产参数模态节点,同表同 id 空间);⑤素材引用 `@id`;⑥注释 `//`。树结构:Node{op,birth,params};**Birth=union(enum){inspire / transform:u64 / aggregate:[]AggIn}**(载荷即输入,种类即输入数——变换零/双输入在类型系统里写不出来);AggIn{in:u64,params};**ParamArg=union(enum){v:Value/r:u64}**(具名工厂的 Zig 化归:构造即显式)。Zig 实现:StringHashMap(器参表)+切片 []AggIn+**arena 承载整树**(parse 进 arena,推倒即销毁)+parse 期名字→id 局部 StringHashMap(u64)+Comps=AutoHashMap(u64,Node){next 发号器永不复用}。**变量名=comp id 本身(2026-10-10,用户)**:.cut 文本里的名字就是 id(`c7=gain(c5,{value:c2})`),单调增+唯一+免命名空间;parse 期名字翻译表作废(零翻译层);可读性归 emit 投影(行尾注释带解析出的语义名/种类,不 baked 进 id);手写/AI 写新节点=向发号器取号;c/p 前缀是阅读衣服不是身份;id 空窗不回收(发号器永不复用)。**id vs name 分工律(2026-10-10,用户)**:comps/素材用 id——运行时创生频繁,需单调唯一,发号器本地发号;插件用 name——**运行时几乎不新造,唯一性由分发期保证**(仓库/单件制:一 cop 一 op 一名,冲突的检测与解决落在文件粒度);id=本地创生的身份,name=分发行列的身份;.cut 里 op 写名(gain),comp 写号(c7)。
- **三类标号记法(2026-10-10,用户)**:三实体三记号三命名空间——合成=`c7`(id,文档级);素材=`@7`(id,库级);效果器=`gain!`(name+`!`,分发级):`!`=宏式声明记号(器声明=展开成结构不是执行,Rust 宏同构);一眼分辨,parser 零歧义,三类引用在文本里各长各样。
- **语法形态修订(2026-10-10,结构字面量式)**:器声明从 C 式调用形 `gain(c0,{…})` 改为 **Zig 结构字面量形** `c1 = gain{ in: c0, value: c2 }`——理由:①语义诚实(.cut 只有声明没有调用;括号调用形暗示"执行",花括号记录形才是"来历声明");②三生统一且**由形状自区分**(启发 `testsrc{ w:1920 }`=只有具名参数;变换 `gain{ in:c0, value:c2 }`=有 `in:` 字段;聚合 `over{ .{in:c1}, .{in:c2,t:300} }`=裸列条目——**`ins:[…]` 这层皮废除**,聚合字面量直接是条目列表;具名字段=器参,裸条目=聚合输入,混排合法);③平级(Zig 式:函数是值,op 名与变量名同格);④AI/LLM 原生友好(匿名结构字面量)。单一形态不备糖(语法糖是伪命题法)。对照:C++ 函数二等公民(函数指针特殊类型/衰变/取址别扭),Zig 函数=一等 const 绑定(`const f = myFunc; f(x)` 统一应用)——.cut 取后者。**聚合参数默认值律**:in 外的槽位全有默认(x=0/y=0/opacity=1/t=0),只写非默认——常见形态塌缩成 `over{ .{in:c1}, .{in:c2,t:300} }`;裸条目形态不可再约,因为"每路输入自带一套参数"是生律,但默认值让它瘦。**字面量内联 vs 常量流(2026-10-10)**:永不变的参数内联字面值(`value: 0.8`)——零 id、零解析、零逐帧拉取,最快;可能动画的归参数流引用(`value: c2`)——买的是可动画性。**判据=会不会动**(器参二分法本意);恒值参数流的短路优化=老法兑现(恒值谱不展开稠密流,实现优化不进语义);OpDecl 可声明"我时间无关",消费者据此把参数提升出帧循环(装配期政策,后置)。**内联常数在 .cut 的性能正名(2026-10-10)**:.cut 是声明语言不是脚本语言——它从不被逐条"执行"(parse 一次→装配一次→之后全是原生器在跑),所以"解释型语言内联常数难优化"的顾虑不适用:**内联常数不是优化,是数据**(ParamArg.v,装配期读一次,零运行时税)。**可问责性判据**:内联字面值=进节点哈希+在 .cut 文本可见——可问责但不可独立寻址;需多处引用/动画化→具名 const 流(器参二分法)。"禁止内联"=过度立法,驳回。
- **声明描述状态,实现只过帧(2026-10-10,用户结晶)**:.cut/树**不存类型**——类型=产方器声明推导(绑死律),文本只声明拓补;**"类型"是承诺不是结构**:视频流并不真的存在,是模拟的(承诺机器);实现形态可违背心智模型(模拟/缓存/优化全藏承诺背后,L1/L2 暗藏合法——缓存透明律)。**任务与状态解耦**:cut 声明状态,任务逐帧递归(每次只要一帧)——所以实现只需优化帧的传递逻辑,流的整体性永不物化;这不是偷懒,是声明与任务各尽职守:声明把状态说全,任务把帧拿准。
- **内联与引用的机制差(2026-10-10)**:内联=**值即操作数**(立即数,零间接、零寿命协调、宽度受限于槽位);引用=**槽里住地址**(两跳访存:读指针再读本体+别名风险+寿命纪律,宽度自由)。完备性不对称:**引用是完备集(一切皆可指),内联是特化快道(小物免税)**——设计顺序=先引用后内联(先把引用做全做正确,内联是零税优化档;ParamArg v/r 即此)。行业对照:CPython/Java 全引用统一但小整数税(装箱/-5..256 缓存 hack);系统语言双通道;JIT 逃逸分析=运行时把引用降回内联。我们的环消息已照此:纸条内联身份(帧号),本体走引用(L1 货架)。
- **字面值=触底点(2026-10-10,用户)**:一切引用链最终触底于字面值——引用复引用,终点必是创建点的常数初值,**内联在源头永不可免**;故参数内联=直接触底,引用=经停站,两者同法,"禁止参数内联"=禁止触底,荒谬(递归触底律的实现形态:触底=字面值)。CPython 注脚:字节码里字面值也不编码进指令流,住 co_consts 常量表按索引装载(LOAD_CONST)——**解释器的"内联"是一跳表查,编译型才烧成立即数**。
- **Slot(T):内联/引用的 comptime 抽象(2026-10-10)**:内联本身解耦成类型函数——`fn Slot(comptime T: type) type { return union(enum){ v: T, r: u64 }; }`(v=值在槽里,r=槽里是身份);引用目标表由槽位位置隐含(器参槽→comps,素材槽→素材表——纯名单无前缀律)。Zig 实现要点:union(enum) tag 自动最小位宽;switch 穷尽性检查=闭集分派免费;payload 捕获 `|x|`;树体 arena 承载。
- **引用链的税与红利(2026-10-10,用户)**:引用链=链式表——表达意图轻松,但**数据占比越小指针税越高**(8B 指针带 4B 浮点=元数据税);随机访问困难(走针 O(n)),但剪辑引用链撑死 ~10 跳,不构成问题。**红利=换头自由**:重定向一根指针,下游全转向——换素材=改素材表条目(地址可变谱不动),换 comp 引用=改父节点一个 id 字段。判据:**内联焊死(零税不可换),引用可换(指针税)**——剪辑是天天换的行当,引用为默认,内联为小标量免税快道。
- **帧协议(器共享的原子单位=帧)**:启发器:无帧入,给 t 吐第 t 帧;效果器:帧→帧;聚合器:多帧→一帧。器分两档(帧器/流器),流器实现=引用并调度帧器;参数随时间(关键帧动画)只活在流器层;帧串装不下变时长效果(时间重映射/残影/回声)——**效果器串废止,封装边界=树节点边界**。
- **聚合先验加速**:时间偏移=改时间戳不碰像素;位移/缩放/透明度=常量几何参数直通(AE 变换栏快的真因=唯一聚合器的先验优化,唯一→先验→高 fan-in=宿主性)。
- **摆放归用法,内容归定义**;聚合参数=摆放的居所。**无根合成**:没有"主时间轴/最终合成",渲染永远对选中的那棵树求值。
