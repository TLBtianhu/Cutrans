## 十四、Zig 地方法规(0.17 实况)

- **工具链**:Zig 0.17.0;zig.exe 等二进制不进公开快照,由 `tools/bootstrap.py` 按固定 URL+SHA-256 恢复;`zig init` 官方样板与 lib/std 源码=API 真源(训练集旧,以样板和源码为准)。
- **0.17 实况**:main 签名收 std.process.Init(init.arena 官方进程竞技场);std.Io 新接口(Mutex/Condition 从 Thread 搬来,lock/wait 带 io 参数可取消;Thread.Mutex 已不存在);build.zig 用 addModule/createModule/addTest/imports 接线;build.zig.zon fingerprint 必须用工具链建议值;struct 字段先于声明;临时量取址是 const(先 var 落成变量);installBinFile 只吃路径字符串(不是 LazyPath)。
- **语法要点**:union(enum) 带载荷;@typeInfo 0.17 改平行数组(field_names/field_types);无 lambda(嵌套 struct 的 fn 代之);无 using namespace(const 绑定即别名);惰性分析(没被引用的 decl 不分析);comptime=普通函数编译期跑(无模板,comptime 全包;模板在 Zig 里=返回 type 的普通函数)。comptime 装载器(loadPlugin:字段名=符号名,inline for 自动填表)已对真 gain.cop 验证——Zig 读 C++ .cop 的 ABI 中立性活体证据。
- **std.DynLib 暂不支持 Windows**(std.Io 重写期撤退)——Windows 班次直接 extern kernel32(LoadLibraryA/GetProcAddress/FreeLibrary),等官方回归再换。
- **模块纪律**:@import 不许越出模块路径;模块依赖用 createModule 的 imports 接线;addTest 按模块挂测试。
- **领土法**:一文件一法律领域;模态特区 modal/(模态盲机制住 src/ 顶层,模态家族包一族一文件夹);内建≠特权,无默认模态,root.zig 不替任何模态代言;bench/=应用方(库 src/ 与应用 bench/ 物理分居;库里零模态词,可 grep 验证)。
- **平台法**:平台性只许住 source/(装载)与将来 ui/(窗口);核永远免适配(纯计算零适配)。WSL2 Ubuntu 保留为第二平台裁判目标:**现役 Zig 目前只重新验收 Windows,旧“双平台全绿”不得当作当前证据;Linux 验收恢复后才准称双绿**;/mnt/c 慢速盘符,干活进 Linux 家目录。平台适配成本律:模型同→改名税;语义异→适配层;范式对立(IOCP/fork)→重设计。
- **WebGPU 落地**:bench/gpu_demo.zig(wgpu-native v29 vendored 于 third_party/wgpu,DLL+头,直 extern);WGSL 计算着色器 256 数翻倍全绿。坑:v29 无 wgpuInstanceWaitAny(用 AllowProcessEvents+wgpuInstanceProcessEvents 循环,mapAsync 用 wgpuDevicePoll)、data 是 WGSL 保留字、WGSL 的 if 必带花括号。WebGPU 哲学:不可变对象(创建期钉死)≠不可扩展(开放集无限造);形状/内容分家(形状编译期,内容运行期);命令录制(encoder)与提交(submit)分离。
- **队列落地**:src/queue.zig Queue(T) 手写版(items+mutex+cond,25 行)测绿;std.Io.Queue 对照(有界+背压+close+取消)。背压=产压平衡的最终物理闸。**容器形状三选(2026-10-10)**:流式 FIFO 单消费者→**环**(定长槽内联值,游标消费读完即死,有界=背压几何);按名直达随机访问→**索引数组/哈希+变长值外挂堆块**(L2:槽={指针,len,状态},blob 各自堆块,逐条寿命归死亡律,增长归落盘保底);多消费者共读→**追加日志+每消费者一个游标**(QQ 信箱/Kafka 同构:以用户分区的 append-only log 持久化,每设备记住自己的读取位点,上线=游标追日志尾;非破坏读,保留归漫游/过期政策)。
- **数字在结构中的身份(2026-10-10)**:数组下标=地址输入(直达);环序号=顺序化身(流转;**写游标即号码机,位置即号码**:槽位=seq mod N,号不必印在槽里,要带号出门就上身=票根/user_data);哈希键=名字的投影;日志序号=时间化身(单调递增永不复用,游标组=各消费者进度);帧号 t=内容身份(幂等律)。**数组=空间结构(位平等,本无游标);游标=时间秩序的具象化**——栈=数组+单游标,环=数组+双游标,迭代器=临时游标。环容量取 2 的幂:回卷=位掩码 &(N-1),二进制溢出=免费取模(麦当劳 999→000 同构;不出错的前提=在途<容量=环的赌注肉身版)。
- **Zig 位宽自由与布局三档(2026-10-10)**:整数任意位宽 u0~u65535(u7/i13/u24 全合法,usize=指针宽);布局三档=普通 struct(编译器可重排字段+对齐填充,最快,形状别依赖)/extern struct(C ABI 保序保填充,FFI/ABI 用)/packed struct(bit 级密排零填充,字段访问=移位+掩码码生成)。三函数:@sizeOf(字节)/@bitSizeOf(位)/@alignOf(对齐)。非 2 幂整型在普通布局向上取整(u24→4B),packed 里正好 24bit;bool 在 packed 里 1bit;enum tag 自动最小位宽,union(enum) 可显式 enum(u2)。packed 的移位税=60 年代付不起的桶形移位器,现在免费——**bit 自由在 Zig 回归,字节先验只剩运输层**。我们的用法:环槽/消息=普通 struct 定长对齐(16B 纸条);落盘/线格式=packed 或 extern;.cop FFI=extern struct。
- **Zig 抽象力之源(2026-10-10)**:**类型是一等值**——type 可作 comptime 参数/返回值/存储,泛型=普通函数返回 type(Slot(T)/Stream(F) 一行成立);**comptime=同一门语言提前跑**(无模板第二语言,无 constexpr 仪式);惰性分析(被引用才编译);无隐藏机制(无 vtable/隐式构造——你写的抽象就是跑的码);模块=struct(文件即结构体,import 即 const 绑定)。**Zig 把语言的第二层(模板/宏/类型系统)压平进第一层——元编程=编程**。对照:C++ 模板=外语(SFINAE/概念补丁);Rust trait 有界;Python 全动态=抽象易但零编译期知识。物理后果:抽象税全付编译期,运行期零税。
- **环的 Zig 声明(2026-10-10)**:模运算是加法器的免费物理(全加器顶端进位无导线可去,自然丢弃——++器天生自带环态);但 Zig 默认 `+` 溢出=非法(Debug/ReleaseSafe 直接 panic)——因为**多数算术里回卷是 bug**(尺寸/价格溢出是事故),语言把免费物理拦下了。要启用环态须显式声明:`+%` 一族(wrapping 运算符,`seq +%= 1`="我要硬件的自然溢出"),或槽位现算 `seq & (CAP-1)`(CAP 取 2 的幂)。**工业环惯用:序号 u64 永不回卷**(2^64 的环实际走不完),槽位=&(CAP-1) 现算——序号保持绝对性,白赚三样:满/空判定无歧义(head==tail 歧义消失)、槽位复用可检(ABA 免疫)、票根免费(seq 本身就是号)。**回卷三法成本阶梯**:位掩码(1 cycle 零分支,要求容量 2 的幂)< 条件减(@subWithOverflow,1-2 cycle,分支永被猜中,任意容量)< 除法取模(几十 cycle,真税,禁用)。
- **环的改造实质(2026-10-10,用户提问结晶)**:环=数组+**钟**——加的不是两根指针,是两个触发式逻辑时钟(push/pop 各敲一下;Lamport 逻辑钟同构:度量的是事件次序,不是墙钟)。改造本质=**空间获得时间秩序**:位置从绝对地址变成相对游标的相位;结构从无状态变成有状态(存货量=两钟之差);寿命从手动变自动(读完即死=**微型 GC**,消费即回收)。牺牲=随机访问与持久性(空间主权:想永久按住 5 号位?没门);换来=流的确定性(O(1)/零分配)+自动寿命管理+背压几何化。数组=纯空间,环=时空合一的流。
- **环的先验清单(2026-10-10)**:收窄访问到"只问下一个",换来结构自带的保证(先验=免运行时验证):①**并发无锁**——双游标把数组分割成生产者区/消费者区,所有权空间化,SPSC 无锁是其直接推论(谁什么时候能碰谁,结构自己知道,故不用锁);②次序免费(FIFO 语义内建);③寿命自动(消费即回收);④访问绝对可预测(预取器全知,下一行永远是下一行);⑤容量封顶+零分配(实时确定性);⑥状态 O(1) 可读(存货=两钟之差)。通法:**收窄问题的集合,答案全变先验**——把运行时检查压缩成结构性纪律(栈=LIFO 先验换性能,环=FIFO 先验换吞吐与无锁)。
- **环的定长槽律(2026-10-10)**:环的 O(1) 底板=地址算术,**要求槽位定长**——故环上消息必须定长(我们选 16B 纸条:刚好的对齐定长,不是最小体积);bit 级变长编码(0/1/10 前缀码)是落盘/网络的税制,环上不收(变长槽=杀死底板)。Zig 工具:enum tag 自动取最小位宽;packed struct=bit 级显式打包;普通 struct=对齐填充(填充是故意买的访问速度)。编译器只优化布局对齐,**不替你设计编码——编码是声明者的责任**。
- **消息的不对称轴(2026-10-10)**:**类型域=闭集**(命令词汇是我们自己立的法,屈指可数——enum(u8) 都奢侈,分派=switch 直写跳表,"闭集直写 switch"法的落点);**身份域=开放**(帧号 i64——内容由声明决定,上不封顶:流可以有几百万帧)。CPU 指令集同构:opcode 闭集、操作数开放。开放性住在"命令指向什么"(op 名/流 id/参数),不住在命令动词集——动词集封闭是宪法级的,插件要新语义就往身份/参数里放,不给动词表添丁。
- **环消息格式规定(2026-10-10)**:①**定长**(底板律,所有槽同宽);②**宽度取 2 幂对齐档**(8/16/32B——缓存行 64B 整除,地址算术免费;默认 16B=4 条/行,真不够升 32B,不取 24B 这类非对齐中间档);③载荷=身份+意图+票根,不带本体不带指针(载荷统一律);④类型域闭集,switch 分派(不对称轴);⑤**参数自限**:能 inline 进剩余字节才进环,放不下的胖负载入侧表、消息带侧表句柄——**宽度由最胖合法消息定,虚胖消息先瘦身再进环**;⑥同进程环用普通 struct(速度优先),端序/packed/extern 归落盘上网(格式法:内部自由,对外从众);⑦票根域可空(0=无回执需求),配对归 SQ/CQ。样例 16B:{kind:u8, flags:u8, stream:u32, ticket:u16, t:i64}。
- **帧号有符号律与行业消息格式通解(2026-10-10)**:t 用 i64 不用 u64——①负时间是编辑域真语义(聚合的相对时间偏移可为负,子流第 -5 帧合法);②下溢安全:t=0 再减=-1(可判非法),u64 静默卷成 2^64-1(灾难);③行业先例=FFmpeg pts 全 i64(AV_NOPTS_VALUE=INT64_MIN 哨兵)。**行业消息格式通解**:定长信封(闭集动词+通用操作数槽+票根)+判别联合(公共前缀,槽宽=最大变体——"宽度由最胖合法消息定"的行业版)+**胖负载走旁路永不进信封**。实例:Win32 MSG={hwnd,message,wParam,lParam,time,pt}(动词+双通用参数);io_uring SQE=定长 64B(opcode 闭集+fd/off/addr/len 操作数+user_data 票根;数据本体经 addr+len 旁路);X11 XEvent=判别联合(公共前缀 type+serial+window);Mach 消息=头部+OOL 描述符(大对象按引用/页重映射过);epoll_event={events:u32,data:u64} 极简;POSIX mq=定长上限 blob+优先级。反例:GPU 命令缓冲=变长包流(AMD PM4),合法因为消费者严格顺序解析永不做槽位算术——**变长的合法性=消费者永不按 i 寻址**。
- **环的底板律(2026-10-10)**:环=数组底板(随机访问物理)+游标纪律——游标的值**算到**元素而非找到元素(地址算术 base+i×宽,O(1) 零搜索);没有随机访问底板,游标就是空号(链表上做不了环:给整数 i 拿不到第 i 个)。纪律结构族(栈/环)全建在这块底板上;自由放置族(链表/堆对象图)无底板故无游标纪律。**环=用随机访问的能力,执行游标纪律的自由收缩**——能力是底板,纪律是政策(纯度在数据结构层:机制与政策分家)。
- **std.Io.Queue 实况(2026-10-10,读 0.17 std 源码确认)**:旧的 std.fifo.LinearFifo/std.RingBuffer 已移除;官方队列=std.Io.Queue(Elem)(Io.zig 内联,2384 行)。init(buffer)=**容量归调用方**(给切片);put/get 满则阻塞空则阻塞(背压+睡醒)+close(关闭后拒 put 但存量排空)+可取消(带 io 参数)+线程安全。**内部就是环**(TypeErasedQueue:buffer+start+len,注释明写 "Ring buffer";回卷用 @subWithOverflow 条件减法而非位掩码——任意容量可行,不限 2 的幂);**等待者优先直交**(getters 优先:有等待中的消费者则数据 memcpy 直递、不进环——环只在双方不同步时当托管方,托管方统一论在 std 里的显形)。std 不带无锁 SPSC/MPMC Disruptor 级环——最热路径的零拷贝环自写(~50 行 std.atomic)或三方库;std.os.linux.IoUring/std.Io.Uring=Linux 侧 io_uring 封装在库。
