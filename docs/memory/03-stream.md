## 二、流协议(细腰核心)

- **帧 = 时间性定死的静态值**(视频帧=一帧画;音频帧=采样窗——单采样无频率,一帧采样才有局部频率)。**流 = 时间是自由变量的序列**;合成永远是流。
- **Stream<F> = { frames, get(ctx,t)→F, ctx }**,pull 接口。三字段=公开数据/公开行为/私有状态的完备分解;句柄走值(24B POD 随便拷),本体走堆(唯一);零值死状态自洽(frames=0 时任何调用都不合法)。
- **流的赤裸性**:流只带顺序时间(第几帧/共几帧);帧率/单位/语义全在器里,不在流里。fps 的家在预览器/导出器(度量时间的唯一消费者)。**句柄字段更名(2026-10-10)**:Stream 的 `ctx` 改名 **`body`**(本体指针)——避免与素材文本后缀 .ctx 撞名;body=堆上本体:器引用/上游句柄/L1 账本/有状态器的滤波器状态(制式永不住这里——制式住声明层)。
- **流=产能的承诺,不是容器**:帧在被拉之前不存在。
- **流只有拉取没有塞入**(开放写=来历失真)。写入三居所:账本内部填充/编辑树(写入的正身)/导出写文件。**修改走树**:写树→哈希变→缓存失效→重新物化→读。
- **唯一产帧动词**:流协议是唯一帧源,万物皆消费者(L2 存入器输入只需帧号 t,自己调 get)。获取动词唯一,存放多处,路由在动词内部,容器不对外开放。
- **流与线程分家(2026-10-10)**:**一 comp 一流**(独立:各自时间轴/各自 L1/寿命锚树版本;多处引用同一 comp id=共享同一流,不复制);**流≠线程≠泵**——流=句柄+闭包+L1 账本的惰性对象,**执行永远借调用方的线程**(链上递归拉取在同一线程同步完成,保底轨零队列零切换);线程只住泵(少数长命共享工人:UI 泵/工作池/播放泵,跨流池化——半岛法);**新建 comp=新建一个结构体,零线程成本**;流生灭随意,泵稀少长命。**两视图**:对外=24B 句柄(frames/get/ctx,按值复印随便传);本体=堆上结构体(**内置 L1 账本+器引用+上游句柄+函数群**,单源原则:raw 唯一出口是它的 get,L1/L2/产线路由藏在动词内部,外部零认知)。结构体=被动物件,它的函数群被调时借调用方线程执行——**含一堆函数的结构体不是线程,泵才是**。
- **访问与生产分家**:MissPolicy{ produce 点播轨(现产填账)/ report 报缺轨(永不触产,返死状态:视频 0×0 空帧、参数 0.0) };wait 档并行时代再加。物化点双动词:get(尊重政策)+ fill(灌注,任务专用),共用账本,幂等不打架。
- **有状态流启发器是原生形态**(粒子/流体:t 依赖 t-1);邻帧窗合法(定长元组=一份静态输入,不破帧定义)。
- **压缩载体**=字节包+解码契约;契约可自描述(CRLE 带魔数/version/w/h)或信封在驻留点,判据=包要不要独立存活。
- **来历链**:用户意图→树→启发器(无中生有)→流器链(有中生有)→帧。唯一生产者是启发器。
