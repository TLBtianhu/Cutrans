## 五、参数世界

- **参数流 = 轻一点的流协议,不是特殊物**;参数世界是合成世界的完整镜像模态(有自己的启发器/效果器/聚合器 trio;关键帧 UI 只是参数流启发器的一个浏览/编辑器)。
- **参数谱** = 用户声明的稀疏源(点列+插值规则,或表达式):内生素材,真源,可落盘,制式无关模态无关。UI 词仍叫"关键帧"。**参数流** = 谱按流制式采样的稠密 f32 序列:派生物,缓存,永不落盘。控制率=帧率(采样级调制不是参数是信号,走流引用)。
- **常量 = 常量启发器**("语法糖"是伪概念:常量表达式本来就是谱的平凡形态;实现可短路恒值谱不展开稠密流——优化不进语义)。
- **参数流启发器三族**:谱采样器(谱 id→流,谱的入境口岸)/ 纯器参启发器(LFO/噪声/表达式/常量)/ 提取启发器(analyze(流,规则):包络/响度/运动跟踪/亮度)。**侧链正解:驱动者永远是被提取/声明的参数谱,不是另一个合成**。
- **参数流效果器**(1→1:平滑/量化/重映射/限幅;量化=音高捕捉)与**参数流聚合器**(N→1:add/mul/加权=模块合成调制矩阵合法化)补齐。
- **递归触底**:参数链可任意深(FM=调制之调制),触底于非器所生的声明(字面值/谱/素材);DAG 无环校验保证触底,环=不可计算,编辑期拒。
- **采样时钟律**:参数流永远在消费者的时间轴上采样(gain 在本地帧采 LFO,聚合在自己的帧采谱;AE 图层透明度关键帧活在父合成时间轴,同构)。
